## 原则

- Session 和图片缓存没有前后依赖，先做 Session 是为了独立验证 Redis 与登录链路。
- 缓存一致性、失败补偿和测试不推迟到最后。审核拒绝、删除和编辑后的公开可见性必须专项验证。
- 暂不缓存管理员审核列表和“我的图片”列表。
- 先确定图片字段，再生成派生文件；生成与清理必须成套实现。
- 第一部分运行说明见 [Redis Session](redis-session.md)。
- 第二部分运行说明及迁移要求见 [Redis 公开图片列表缓存](redis-picture-cache.md)。
- 第三部分容量、过期、跨实例失效与故障边界见同一文档的「第三部分 Caffeine 本地缓存」。
- 第四部分字段语义、迁移和文件清理边界见 [图片原图与派生图存储策略](image-storage-strategy.md)。
- 第五部分派生图规则、回退和配置见同一存储策略文档的「新上传与替换」。

### 缓存受控对比

环境：本机 Java 21、真实隔离 Redis 7.4.11、H2 内存数据库 1001 行、每页 12 条。调用真实 Service/MyBatis/缓存链路，作者资料服务使用测试替身；无 HTTP 网络、真实 MySQL 或多用户并发。三轮轮换模式顺序，每种模式每轮预热 100 次、计时 300 次，断言返回 1001 条总数和 12 条记录，不断言某模式必须更快。

| 模式 | 第一轮 p50/p95 ms | 第二轮 p50/p95 ms | 第三轮 p50/p95 ms |
| --- | --- | --- | --- |
| 关闭图片缓存 | 2.534 / 4.107 | 1.219 / 2.236 | 1.018 / 2.180 |
